# The Champions Club

Sports Club Management System — one system for courts, shop & bar.

Built for the **Odoo × LPU Jalandhar Hackathon**.

## What it does

The club runs on WhatsApp, Excel and paper today. This project replaces all of that with one platform:

- **Memberships** — Gold, Silver and Junior plans, with expiry tracking
- **Court booking** — tennis & cricket, 1-hour slots, no double-booking
- **Shop** — rackets, balls, shoes & apparel, one stock for counter and online orders
- **Bar & cafe** — POS with member discounts, tabs and daily earnings
- **Website** — plans, court availability, shop and trial booking
- **Owner dashboard** — courts + shop + bar revenue in one place

## Tech stack

- **Front-end:** Next.js + React + TypeScript, Tailwind CSS
- **Back-end:** Odoo 20 (headless) + PostgreSQL
- **Payments:** Razorpay test mode (online), Cash / Card / UPI (counter)
- **Auth:** Odoo — owner & staff only, members need no login
